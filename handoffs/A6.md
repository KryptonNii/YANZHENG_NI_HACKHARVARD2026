## How to run

From `api/`. These are two different entry points.

- Application factory, the same one `make dev` uses. `--factory` is required because `create_app` is a function:

  `uv run --project . uvicorn --factory trialpilot_api.main:create_app --host 127.0.0.1 --port 8006`

- ASGI app object. `app` is not the factory. Importing the module does not build it; the first read of `app` calls `create_app()`:

  `uv run --project . uvicorn trialpilot_api.main:app --host 127.0.0.1 --port 8006`

Both were loaded in this pass. The factory served `GET /api/health` and the ops routes on port 8006 against a temporary `TP_DATA_DIR`. Pointing uvicorn at `trialpilot_api.main:create_app` without `--factory` does not serve the API.

## Known risks

- The evaluation is synthetic and covers three deterministic seeds, not clinical validation. Seed 7 intervention I3 is a true no-effect case whose confidence interval includes zero, so the verdict stays `inconclusive`. Thresholds and equivalence rules were not changed to relabel it as `no_effect`.
- Alert thresholds and un-sourced costs, emissions, and time values are assumptions; impact estimates must be read with their provenance and ranges.
- API process restart discards the current simulation run and its event replay history. Simulation labels do not survive a restart.
