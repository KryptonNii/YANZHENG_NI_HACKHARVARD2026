## Known risks
- Real-trial totals are only as complete as the library: any missing id makes its terms unknown (`null`),
  named in warnings (0 missing on NCT03930732, CASPS, and PRIMETIME this pass).
- Science-check totals with WTT are +23.4% (CASPS) and +22.7% (PRIMETIME) versus published. The +5.3%
  and +7.2% figures are the same runs with WTT omitted. Published totals are still inside P10–P90.
- `compute_scenario` under 300 ms does not mean the uncached API is under 300 ms. This pass the
  120-site API path, including A3, was about 2.2 s, mostly supply.
- Ranges reflect parameter uncertainty of averages only (one draw per parameter), not between-patient variability.
- `compare` relies on an in-process registry; after a JSON round trip use `compare_levers`.
