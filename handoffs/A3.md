## Plan
1. `forecast.py`: Poisson–gamma recruitment (site rate λᵢ ~ Gamma, per-site activation ~ triangular).
   Exact time-to-n via the time-change theorem (n-th arrival = M⁻¹(Gamma(n,1))), vectorised over draws × sites.
2. Milestones FPI / LPI / LPLV / DB lock, duration, enrollment curve P10/P50/P90; dropout inflates enrolment.
3. `update_with_actuals`: conjugate Gamma update per site, then forecast the remainder from the data cut-off.
4. `supply.py`: weekly per-site inventory simulation (FIFO expiry, lead time, safety stock), upfront vs
   on-demand on the same patient draws; waste = expired + destroyed at close; stockout probability + warning.
5. Every parameter from the library; missing ids fall back to built-in `assumption: true` defaults and
   produce a warning (never silent). Provenance items for A2.
6. Tests: rate recovery, posterior moves to actuals, site exclusion, zero-site error, conservation,
   on-demand ≤ upfront waste, expiry, determinism, quantile order, perf (120 sites × 2,000 draws < 1 s).
7. `docs/model_forecast.md` (formulas, parameters, calibration) + example output for a 40-site design.
