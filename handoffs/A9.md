# A9 — Web command center + compliance pages — HANDOFF

## Plan
Command center on A6 (`/api/ops`), approvals/audit/validation on A7, using A8's `request`, identity switcher and UI kit. Smallest slice first (alerts → intervention, self-approval, chain verify, DRAFT stamp), then the full pages.

## Done
- `/command/:trialId` (`web/src/features/command/`): simulated-feed badge, clock, Start/Restart, Advance 1 week / 6 weeks, 14 KPI tiles (ranges, missing impact shown as "not estimated"), country/site drill-down with a plan-band marker, live alerts (acknowledge / plan intervention / dismiss with reason), intervention tracker with difference-in-differences verdict and before/after chart, collapsible event ticker. SSE refreshes the board.
- `/approvals`, `/audit`, `/validation` (`web/src/features/compliance/`): named exports `ApprovalsPage`, `AuditPage`, `ValidationPage` plus a default export. Sign dialog limits the meaning to the next step, re-enters the PIN, and maps `self_approval_forbidden` to "Authors can't approve their own work." Audit verify shows "Chain intact — N entries" or "Broken at seq X". Validation renders deliverables, the traceability matrix (untested requirements flagged), defect counts and QA sign-off, with the DRAFT stamp.
- Demo trial id is `demo-40` (A6). The nav link `/command/demo` offers a jump to it when that id has no design.

## How to test
- Unit: `pnpm --dir web exec vitest run src/features/command src/features/compliance` → **4 passed** (alert → plan intervention; self-approval message; intact and broken chain; DRAFT stamp + untested URS-003).
- E2E (real API, A9 ports): `E2E_WEB_PORT=5182 E2E_API_PORT=8009 pnpm --dir web exec playwright test e2e/command.spec.ts e2e/compliance.spec.ts` → **2 passed**. `E2E_MOCK=1` skips them (A8's mock does not serve ops or the audit chain).
- Tags: `// @req URS-011 URS-012 URS-013` (command), `// @req URS-017 URS-021 URS-032` (compliance).
