## Done (how to run / test)
**Compliance layer** (`api/trialpilot_api/compliance/`, stdlib sqlite3 + argon2-cffi):
- `audit.append(...)` — SHA-256 hash chain (genesis = sha256("trialpilot-genesis")); SQLite triggers abort UPDATE/DELETE on
  `audit` and `signatures`; `verify_chain()` → `{ok, first_bad_seq, checked, head_hash, problem}` (optional recorded anchor
  detects tail truncation); CSV export of every entry.
- `esign` — PIN re-auth (argon2id of `TP_SECRET_PEPPER`+PIN), 401 wrong PIN, 3rd failure → 423 + 5-min lock, all audited;
  signature bound to record sha256; validity re-checked on every read (`records.register_resolver` / file records);
  §11.50 manifestation (printed name, username, role, MEANING, UTC time, record hash). AI actors (`ai:*`) can't sign.
- `roles` — demo users + permission matrix (`validation/ROLES.md`, test keeps doc = code). Role comes from the registry, never the request.
- `workflow` — scenario/test_protocol/change_record: reviewed → approved; validation_report: approved (QA). 403
  `self_approval_forbidden` (any role, incl. QA), 409 `out_of_order`, 403 `duplicate_signer`, QA-only final approval,
  409 `record_changed`, 409 `already_pending`/`request_closed`; every action and every denial audited.
- `routes.router` (absolute paths, mounted by A5): `/api/audit`, `/api/audit/verify`, `/api/audit/export.csv`,
  `/api/approvals[/{id}[/sign|/reject]]`, `/api/signatures`, `/api/compliance/users|roles`, `/api/validation/package[/files/…]`.
- Contract **v3** (my proposals, accepted by A1): `Signature.signer_name`, `ApprovalRequest.record_hash/created_at/title` — migrated.

**Validation toolkit `tpv`** (`validation/`, see `validation/README.md`): `plan` (GAMP category drafted as DRAFT) · `risk` ·
`protocol [--submit]` (tests per requirement, deterministic, record id = `OQ-TP-001-<sha8>`) · `sign`/`reject` (PIN) ·
`execute` (**refuses unless the exact protocol version is approved**; runs every package suite in its own venv + Playwright
with `--e2e`; `evidence_manifest.json` with sha256/size/UTC mtime of every file, executor, git commit; signed `executed`) ·
`trace` (flags no-test requirements, untagged tests, unknown ids, below SOP depth) · `report [--submit]` (real counts;
"awaiting QA approval" until QA signs; edit after signing → "approval invalid") · `impact --base --head` (component map →
requirements → tests → change record draft) · `package` (Markdown + HTML + `package_index.json` for A9) · `controls`
(10 compliance control probes) · `defects-run` · `effort` · `verify-evidence`.
Inputs: `company_sop.md` (fictional), `requirements.yaml` (32 URS, H/M/L + GxP with rationale), `component_map.yaml`,
`tpv_config.yaml`, `ROLES.md`, `PART11.md` (21 CFR 11.10/11.50/11.70/11.200/11.300 — each opened on eCFR 2026-10-16, gaps stated).
