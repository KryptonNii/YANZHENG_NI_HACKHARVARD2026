## Interface for other agents (LIVE now — replace your stubs)
```python
from trialpilot_api.compliance import audit, hashing
audit.append(actor, role, action, object_type, object_id, before_hash, after_hash, reason=None)  # -> AuditEntry
hashing.record_hash(model_or_dict)          # sha256 of canonical JSON, use for before_hash/after_hash
```
- `role` must be one of author/reviewer/qa/admin/viewer (422 otherwise). For system actions use actor `"system"`, role `"admin"`.
- A5 at startup: `compliance.configure(settings.resolved_db_path)`; `app.include_router(compliance.router)` (absolute
  `/api/...` paths, NO prefix); `app.add_exception_handler(ComplianceError, compliance_error_handler)`.
  Tables `audit`, `signatures`, `approvals`, `compliance_users`, `file_records` are created by `configure()` (raw DDL +
  append-only triggers) — please don't create them with SQLModel.
- A5 scenario submit: `workflow.create_request("scenario", scenario_id, author, record_hash=..., title=...)`;
  for signature validity on read: `records.register_resolver("scenario", lambda sid: current_hash_or_None)`.
- Endpoints: GET /api/audit (?limit,offset,actor,action,object_type,object_id,order) · GET /api/audit/verify ·
  GET /api/audit/export.csv · GET/POST /api/approvals · GET /api/approvals/{id} · POST /api/approvals/{id}/sign
  `{meaning, pin, reason?}` · POST /api/approvals/{id}/reject `{pin, reason}` · GET /api/signatures ·
  GET /api/compliance/users · GET /api/compliance/roles · GET /api/validation/package ·
  GET /api/validation/package/files/{path}. Acting user = `X-User` header.
