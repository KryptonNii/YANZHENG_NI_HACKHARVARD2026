# Judge questions

Use these one-sentence answers with the [build status](../README.md), [claim ledger](EVIDENCE.md) and completed handoffs; required controls remain targets until execution evidence exists.

1. **Isn't this just Evinova?** Evinova already describes multi-metric design and carbon estimation, while we explore an MIT implementation linking visible assumptions to synthetic operations and software evidence. [Sources](EVIDENCE.md).

2. **Where does real data come from?** ClinicalTrials.gov supplies registry metadata and publications supply reference figures, while absent schedules and operating feeds require assumption or synthetic labels. [A4](../handoffs/A4.md).

3. **How accurate are the carbon numbers?** Input completeness, factors and boundaries limit accuracy, and reproduction gaps require A10's actual generated output rather than a universal accuracy claim. [Method](https://pmc.ncbi.nlm.nih.gov/articles/PMC10823997/).

4. **Would QA accept AI-generated validation documents?** AI drafts require human review, actual execution evidence and authorized independent signatures, so the responsible QA organization decides acceptability.

5. **What's simulated?** EDC, CTMS, IRT, travel and courier operating feeds are synthetic, assumed schedules stay labelled, and UI mocks require a separate disclosure.

6. **Why should Regeneron care about carbon?** We lead with cost, site workload, timing and patient burden, then use carbon as another metric for the same choices.

7. **Do P10 and P90 mean you're right most of the time?** They are quantiles conditional on model assumptions and input ranges without demonstrated coverage of real outcomes.

8. **Does a home visit always save money?** Home nursing and logistics can add cost, so we show a trade-off with travel and workload only when the computed output supports it.

9. **Can an author approve their own work?** The required workflow rejects self-approval and uses distinct review and approval roles, with proof dependent on A7's executed checks and UI rehearsal.

10. **Are the signatures and audit trail production compliant?** They are prototype controls needing production identity, security, retention and QA assessment, with no certification or regulatory-acceptance claim.

11. **How do you know an intervention worked?** The intended difference-in-differences estimate compares treated and control changes under fallible assumptions, and synthetic output establishes no clinical causal effect.

12. **Does it work without the internet?** Cached-fixture offline operation is required, but the disconnected walkthrough remains a rehearsal gate and dependency installation needs preparation.

13. **Does reproducing footprints validate the whole product?** It checks only the disclosed carbon computation path for those cases, while costs, workload, forecasts and intervention estimates need separate evidence.

14. **How many defects did you catch and how fast is it?** These measurements await A7 and A2/A5 handoff evidence, including detected/attempted counts and latency run conditions.

15. **What does a real pilot need?** A pilot needs permitted data, sponsor/site review, production controls, defined acceptance criteria and comparisons between estimates and observed operations.
